# 后台安全说明

普通安装问题可[提交 Issue](https://github.com/richzorya/mind-universe-release/issues/new/choose)。疑似漏洞或秘密泄露时，请优先使用发行仓库 **Security → Advisories → Report a vulnerability** 私密报告；如果没有该按钮，也没有既有私密联系方式，只在 Issue 中写“需要私密联系，涉及安全问题”，等维护者提供私密通道后再发送细节。

报告可包含版本、发生时间、不含秘密的错误和使用虚构资料重现问题的步骤。不要上传 `MU-installation` 文件、`INSTALL_CONFIG`、配对码、设备凭据、模型 API Key、Cloudflare 管理令牌或私人聊天。

如果供应商密钥泄露，请到对应服务商撤销或轮换，并检查异常请求与账单。后台安装配置或配对凭据泄露时，先停止后台任务并通过私密渠道排查；更换配对码不会自动撤销已登记设备，不要删除原配置或重新生成加密密钥，以免失去旧数据的解密信息。删除公开帖子也不会让已复制的秘密失效。

只在自己有权使用或明确获授权的环境中开展安全研究，不访问他人数据。本说明不授予第三方系统的测试权限；不承诺固定响应时间或漏洞奖金。
