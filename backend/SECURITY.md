# 后台安全说明

普通安装问题可[提交 Issue](https://github.com/mind-universe-studio/mind-universe-release/issues/new/choose)。使用中发现涉及安全、密钥或私人数据的问题时，请沿用已经从作者本人取得的私密渠道；尚无该渠道时，请提交[联系作者请求](https://github.com/mind-universe-studio/mind-universe-release/issues/new?template=contact_request.md)，只写“需要私密联系，涉及安全问题”或“需要私密联系，涉及隐私请求”，等作者提供私密渠道后再发送必要资料。

公开联系请求中请勿填写问题利用方法、个人资料、联系方式、账号信息或任何密钥。取得私密渠道后，可提供版本、发生时间、不含秘密的错误和正常使用中触发问题的步骤。不要上传 `MU-installation` 文件、`INSTALL_CONFIG`、配对码、设备凭据、模型 API Key、Cloudflare 管理令牌或私人聊天。

如果供应商密钥泄露，请先到对应服务商撤销或轮换，并检查异常请求与账单，再移除公开内容。后台安装配置或配对凭据泄露时，先停止后台任务并通过私密渠道联系作者。配对码控制新设备连接，已登记设备的访问凭据需要单独处理；请保留原安装配置和加密密钥，以便处理访问权限并保护已有数据。

请勿访问他人账号或数据、干扰服务运行。对产品及作者代码的使用须遵守随附的[学习交流使用条款](LICENSE.txt)与[免责声明](DISCLAIMER.md)。
