# 常见问题

[返回首页](../README.md) · [安装教程](INSTALL.md)

## Cloudflare 和 Netlify 要同时注册吗？

不一定。后台需要 Cloudflare 账号。网页如果也放在 Cloudflare Pages，只用 Cloudflare 即可；网页选择 Netlify 才需要再注册 Netlify。已有可用网页地址时，不必自己再部署网页。

## 这是免费的吗？

软件按[个人非商业许可](../LICENSE.txt)提供，不收取该范围内的软件许可费。Cloudflare、Netlify、域名、模型和语音是不同的服务，可能有免费额度，也可能产生费用，互不抵扣。请以你自己账号的套餐和账单为准，不要把“免费部署”理解成“AI 免费使用”。

平台说明：[Cloudflare Workers](https://developers.cloudflare.com/workers/platform/pricing/)、[D1](https://developers.cloudflare.com/d1/platform/pricing/)、[Workflows](https://developers.cloudflare.com/workflows/reference/pricing/)、[Netlify](https://www.netlify.com/pricing/)。额度耗尽时可能报错或暂停，是否计费取决于对应套餐。

## 后台地址、配对码和 API Key 有什么区别？

| 名称 | 从哪里得到 | 填在哪里 |
| --- | --- | --- |
| 网页地址 | 网页部署完成后由 Cloudflare Pages / Netlify 提供 | 浏览器地址栏；安装后台时也需要它 |
| 后台地址 | 安装结果文件里的 `backendUrl` | 设置 → 个人后台 |
| 配对码 | 安装工具生成，结果文件里的 `pairingCode` | 设置 → 个人后台 |
| 模型 / 语音 API Key | 你选择的 AI 服务商 | 应用的 API Keys 页面 |

Cloudflare 登录授权只在电脑上通过官方 Wrangler 完成，不需要把管理令牌交给作者或填进网页。

## 安装失败怎么办？

- **找不到 node / npm**：确认已安装教程要求的 Node.js，关闭并重开终端。
- **找不到 install.mjs 或检查失败**：确认进入的是后台 ZIP 解压目录，不是网页包或 GitHub 仓库快照；损坏的包应重新下载。
- **目录权限不合适**：安装信息须放在当前用户独占的本机目录，不放在共享盘、同步盘或 Git 仓库中。不要通过放宽权限绕过检查。
- **未登录 / 没有权限**：重新运行教程中的 Wrangler 登录与 `whoami`，核对 Account ID 和当前账号权限；新账号确认已设置 workers.dev 子域名。
- **准备过一次或准备中断**：不要反复执行首次准备命令，也不要删除安装目录。完整的已有安装或升级使用原记录；准备只完成一半或密钥丢失时，保留现场寻求帮助。
- **创建数据库时中断**：先停止重试，在 Cloudflare 控制台确认数据库是否已创建，再提交不含秘密的错误提示寻求恢复帮助。不要另建目录再装一次，也不要随意改安装记录。

安装工具可能只显示统一失败提示。可以在本机查看 `installation.json` 的进度：若停在 `creating-database` 且 `databaseId` 为空，需要先确认原数据库；若已保存 `databaseId`，可修复网络或权限后，用同一安装目录重新执行 `--apply`。不要公开上传 `installation.json`、`worker-secrets.json` 或 `pairing-result.json`。

## 网页能打开，但后台连接不上？

1. 确认填写的是后台地址，不是网页地址，没有多余空格、路径或引号。
2. 确认复制的是同一个后台的配对码，不是 Cloudflare 密码或模型密钥。
3. 确认当前网页域名与安装时填写的地址完全一致；换了域名不能直接沿用旧的允许名单。
4. 核对自己的 Cloudflare 后台是否安装成功，账号是否被暂停或额度耗尽；换个可用网络再试。

仍失败时提交页面显示的错误文字、安装版本和系统版本，不要发配对码、密钥或完整后台日志。中国大陆等地区的网页与后台连通性需分别测试，更换网页平台不一定能解决后台不可达。

## 使用自定义模型中转地址时被拒绝？

个人后台只访问允许名单中的可信 HTTPS 模型域名，避免成为任意网络代理。第三方中转地址可能需要额外配置，不是任何网址都能直接使用。不要为排错关闭鉴权或把所有域名放行；提交不含密钥的服务域名与错误提示确认兼容性。

## 我的数据会经过作者的后台吗？

个人后台版的模型、语音和后台任务走你连接的实例；未连接或故障时不会自动借用作者后台。网页下载仍经过托管平台，模型请求仍需云平台和服务商处理；自有后台也不等于任何人都无法接触数据。具体见[隐私说明](../PRIVACY.md)。

## 为什么后台任务会暂停，或者旧结果找不到了？

应用已有后台保护：**每个设备与整个后台实例，每个 UTC 日各最多 500 次任务**，当前没有关闭开关；任一预算达到上限后停止对应的新后台模型任务，已有结果仍可收取，下一个 UTC 日恢复。这不是 Cloudflare 免费额度，普通前台聊天不按这项后台任务预算计数。

云端生成结果最多保留 **72 小时**，收取确认后清除。请及时打开应用收取，并备份重要记录；平台和 AI 服务商还可能有自己的限制。

## 更新、迁移与停用

### 怎样更新？

1. 先导出本机备份，关闭后台回复和自主聊天，确认云端停止并收取已有结果。
2. 从同一新版本下载网页与后台包，先读版本说明中的兼容性和迁移要求。
3. 网页：自己部署的，向**原站点**上传新的网页包，保留原网址；使用他人提供的网页地址时，由网页提供方更新，你不需要下载或上传网页包，只更新与该网页兼容的后台。
4. 后台：进入新版后台解压目录，重新设置安装教程中的 `MU_WRANGLER_JS` 与 `MU_STATE_DIR`，其中安装目录必须与初装时一致，然后执行同一条 `--apply` 命令。**不再执行 `--prepare`。**
5. 打开网页确认连接，并发送一条测试消息。

请保留上一版包和安装目录。加密密钥、数据库和后台身份必须沿用；丢失安装记录时先停止升级，不要新建一套冒充原实例。数据库迁移后不能保证直接上传旧版就能回退，先咨询恢复方法。

### 换手机或换网址呢？

聊天记录主要在本机，不会因为登录同一个 Cloudflare 自动同步。先在原设备、原网址导出备份，再在新设备导入并重新配对。换网页域名还需要更新后台允许访问的网页地址；不要先删旧站点或旧记录。

### 不用了，怎么停用？

1. 在应用中关闭后台回复和自主聊天，确认云端停止，收取结果并导出备份。
2. 再断开个人后台连接；这不会自动删除云资源，也不会撤销已配对设备。
3. 确定不再使用后，可在自己的 Cloudflare 控制台按 `installation.json` 中记录的名称删除本次安装的 Worker、两个 Workflows 和 D1。请逐项核对，不要删其他项目；**删除数据库后，其中的数据无法通过重新安装恢复。**
4. 需要时再删除自己的网页站点和本机数据。平台日志、备份及既有费用按平台规则处理。

如果后台无法连接，不能把本地断开当成云端已停止，请先核对自己的 Cloudflare 资源。当前没有自动卸载或一键撤销全部设备功能。
